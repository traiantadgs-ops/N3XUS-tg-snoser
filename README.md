# 🚀 N3XUS Telegram Snoser (NTS)

Высокопроизводительный многопоточный инструмент для автоматизированной отправки обращений и жалоб в службу поддержки Telegram (`telegram.org/support`) с динамической ротацией живых HTTP-прокси.

---

## ⚡ Особенности
- **Динамический пул прокси:** Автоматически сканирует бесплатные прокси с ProxyScrape API и проверяет их на работоспособность перед использованием.
- **Многопоточный «Пулемет»:** Отправляет запросы параллельно (`ThreadPoolExecutor`), обеспечивая высокую скорость работы.
- **Автоочистка мертвых IP:** Если прокси отваливается или выдает ошибку, он мгновенно удаляется из пула.
- **Многопоточные сканеры:** 10 фоновых потоков непрерывно ищут и сохраняют рабочие прокси в файл `working_proxies.txt`.
- **Ротация User-Agent и данных:** Рандомизация заголовков, генерация случайных номеров телефонов и почтовых ящиков для каждого запроса.
- **Полная база категорий:** Поддерживает все типы жалоб (Спам, Порнография, Фишинг, Дианон, Мошенничество, Сессии и др.).
